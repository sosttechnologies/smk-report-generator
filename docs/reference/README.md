# Reference material

The fidelity target for this project. **These are the spec** — when code and these images
disagree, the images win.

- `report-page-*.png` — SIEVEMK's existing six-page Interim Termly Report (George Holmes,
  Spring 2026). The PDF export must match this: page order, the 8-column subject matrix,
  the 8 label/body sections, Calibri, the letterhead footer on every page.
- `form-*.png` — the blank "SMK STUDENT PROGRESS REPORT" Microsoft Form tutors complete
  weekly. Ten questions; see `.claude/skills/smk-form-schema/SKILL.md`.

The names in the report images are from SIEVEMK's own worked example. Do not add screenshots
containing real students' details to this repository.
